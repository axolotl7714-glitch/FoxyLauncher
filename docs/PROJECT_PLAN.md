🦊 FoxyLauncher – Project Plan

Our vision

FoxyLauncher is a simple, stable Minecraft launcher with a cute orange fox and its own little cave as the home screen.

Supported platforms

- Android
- Windows
- Linux
- macOS
- iOS/iPadOS (technical feasibility to be investigated)

First version – 0.1

Launcher

- Foxy cave home screen
- Animated fox mascot
- Play button
- Settings menu
- Minecraft version selection
- Minecraft installation

Client features

- FPS counter
- Keystrokes
- CPS counter
- Fullbright (later)
- Own cosmetics (later)

Stability first

- Test every feature separately.
- Check mod compatibility before installation.
- Verify downloaded files.
- Save error logs.
- Avoid unnecessary features.
- Fix crashes before adding more features.

Account and cosmetics

- Use official Microsoft authentication for Minecraft.
- Build independent FoxyClient cosmetics.
- Connect LabyMod features only through officially supported interfaces and permission.

Development roadmap

1. Project foundation
2. Launcher interface
3. Foxy cave and mascot
4. Installation system
5. Minecraft launch support
6. Basic client features
7. Desktop versions
8. Investigate iOS support

Main goal

A lightweight, reliable Minecraft launcher that is easy to use and does not crash unnecessarily.
